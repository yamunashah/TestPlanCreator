## 4. 📋 Acceptance Criteria

1. User can enter email and password on the login screen.
2. System displays a clear validation error for invalid credentials.
3. System locks account after 5 consecutive failed attempts.
4. Successful login redirects to user dashboard within 2 seconds.
5. Session token expires after 15 minutes of inactivity.
